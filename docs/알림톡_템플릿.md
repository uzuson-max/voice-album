# 알림톡 템플릿 (솔라피 → 카카오 심사용)

자녀에게만 알림톡으로 보낸다. 부모님 질문은 지금처럼 문자.
아래 문구를 **띄어쓰기·줄바꿈까지 그대로** 등록한다. 변수 이름(`#{부모님}` 등)이 코드와 같아야 발송된다.

등록 위치: 솔라피 콘솔 → 카카오 → 알림톡 템플릿 → 새 템플릿 → 채널 `우리집 레코드` 선택

---

## 1. 이야기 도착 (arrival)

- 템플릿 이름: `이야기 도착`
- 메시지 유형: 기본형
- 카테고리: 서비스이용 > 이용안내/공지 (가장 가까운 것)

본문:

```
#{부모님} 들려준 이야기가 도착했어요.

‘#{제목}’

목소리와 함께 이야기 화면에서 읽어보세요.
```

버튼 1개:
- 버튼 종류: 웹링크
- 버튼 이름: `이야기 보러 가기`
- 모바일 링크: `https://voice-album-9uvm.vercel.app/app/stories`
- PC 링크: 같은 주소

변수 예시 (심사용으로 적는 칸이 있으면):
- `#{부모님}` = 엄마가
- `#{제목}` = 스무 살 거울 앞에서

---

## 2. 보관 기간 안내 (keep)

- 템플릿 이름: `보관 기간 안내`
- 메시지 유형: 기본형
- 카테고리: 서비스이용 > 이용안내/공지

본문:

```
#{부모님} 이야기 보관이 #{날짜}에 끝나요.

그 전에 목소리·영상 원본을 내려받아 두세요.
```

버튼 1개:
- 버튼 종류: 웹링크
- 버튼 이름: `원본 내려받기`
- 모바일 링크: `https://voice-album-9uvm.vercel.app/app/export`
- PC 링크: 같은 주소

변수 예시:
- `#{부모님}` = 엄마
- `#{날짜}` = 11월 30일

---

## 심사 통과 후 Vercel 환경변수 3개

| 이름 | 값 |
| --- | --- |
| `SOLAPI_KAKAO_PFID` | 솔라피에 연동한 채널의 pfId (KA01PF…) |
| `SOLAPI_KAKAO_TPL_ARRIVAL` | 1번 템플릿 ID (KA01TP…) |
| `SOLAPI_KAKAO_TPL_KEEP` | 2번 템플릿 ID |

넣고 다시 배포하면 그때부터 알림톡으로 간다. 넣기 전, 또는 알림톡이 실패하면 같은 내용이 문자로 간다.
